## Deploy
Deploy this folder as its own Vercel project/repo. `index.html` is the app. `api/presto-live.js` is a Vercel Function that retrieves the public Presto JSON without using cookies, logins, or access-control bypasses.

## Adding future games
Add a verified source entry to `SOURCES` in `api/presto-live.js` after the official Game Centre exposes its public `liveupdate` request. Do not invent or reverse engineer the `h` value. Capture the value generated by the official public Game Centre.

The frontend polls the app's own `/api/presto-live?game=...` route every 10 seconds, only for games registered as verified Presto sources. It will remain in pregame mode if no verified live response is available.
