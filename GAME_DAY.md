# Game-day guide

Upcoming schedule cards and pregame centres share venue resolution, kickoff, Watch/Tickets/Directions links and a downloadable calendar event. No database or Supabase is used. The guide uses the dated national schedule rather than temporary UI hydration state. Finals, past fixtures and postponed/cancelled games are excluded. Explicit venue overrides take precedence; unconfirmed neutral venues never borrow home addresses or tickets.

School links in `data/game-day-schools.json` and `game-day-data.js` were researched October 14, 2026 from schools' official athletics navigation and official ticket/visitor pages. School ticket pages are labeled accordingly, not presented as guaranteed event tickets. Missing tickets, street addresses, parking and RSEQ broadcasts are marked as unannounced/unverified. No ticket prices, access promises, parking rules or unverified streams are invented. Existing OUA event links are reused; Canada West and AUS use their conference portals. Existing podcasts and community features are retained.

Confirmed address sources: UBC official Thunderbird Stadium page; Toronto Varsity Blues ticket information; uOttawa Gee-Gees Field facilities page; CEPSUM contact page. Extra verified ticket sources include Laurier's 2026 football announcement, Queen's 2026 ticket announcement, Laval's football tickets page, Carabins' ticket hub and Sherbrooke's football game-day guide. Directions use the resolved stadium and city, not a guessed street address. Home venues carry an explicit label.

Calendar downloads convert the schedule's explicit timezone abbreviation to UTC, handle midnight rollover, escape/fold iCalendar content, and reserve a clearly documented 3-hour window. Missing kickoff times produce a date-only reminder. Visitors should check the game page for changes; this is a download, not a subscribed calendar.

`/api/game-weather?game=<known schedule ID>` performs a fixed Canadian city/province geocoding lookup and fetches Open-Meteo's daily forecast for that game's date, within 16 days. City-level daily high/low, precipitation probability and maximum wind are labeled distinctly from conditions at kickoff. Responses are cached for an hour, and unsupported dates, unknown locations, incomplete values and provider timeouts get a graceful fallback with an Environment Canada forecast link. No user coordinates, API keys or arbitrary upstream URLs are accepted. The forecast upstream timed out during local testing; verify availability on the deployed endpoint. Open-Meteo public endpoint terms apply; a commercial plan can be configured if the site becomes commercial.

Validation: game-day, existing community and venue checks; actual browser calendar download; 13 upcoming card mounts; OUA event link; neutral venue handling; desktop/mobile layouts and live production verification.
